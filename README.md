#Minecraft Server Landing Page

Одностраничный сайт-визитка для Minecraft-сервера. Адаптивный, с живым анимированным фоном и слайдером.

##Что это? 🤔

Демонстрационный лендинг, который я сделал для портфолио. Показывает, что я умею:
- Верстать адаптивные сайты под ПК, планшет и телефон.
- Работать с HTML, CSS и чистым JavaScript (без фреймворков).
- Создавать анимированный фон на `<canvas>`.
- Делать интерактивные элементы: слайдер, бургер-меню, кнопки.

##Технологии 🛠️:

- **HTML5** — разметка
- **CSS3** — стили, адаптив, анимации
- **JavaScript (Vanilla)** — слайдер, бургер-меню, canvas-фон
